¡Bienvenido a mi repositorio de prácticas de **Visión Artificial**! 🚀

Este repositorio alberga una serie de ejercicios y scripts desarrollados en Python por [@Shayko-stack](https://github.com/Shayko-stack). El enfoque principal de todo el código aquí presente es la **Segmentación de Imágenes** y el análisis visual mediante diversas técnicas de procesamiento.

> 📺 **Créditos y Referencia:** 
> Todas las prácticas realizadas en este repositorio están basadas y guiadas por los excelentes tutoriales del canal de YouTube **[Proyectos JC](https://www.youtube.com/@proyectos-jc)**. Gran parte del aprendizaje, la lógica implementada y los ejercicios provienen de su contenido.

## 🛠️ Tecnologías y Librerías Utilizadas

El código está desarrollado y probado de forma local utilizando **Python 3.11.5** en un entorno Windows. Las herramientas principales para lograr la segmentación son:

* **Procesamiento y Segmentación de Imágenes:**
  * OpenCV (`cv2`)
* **Manipulación de Datos, Arreglos y Visualización:**
  * NumPy
  * Matplotlib

## 🚀 Cómo ejecutar las prácticas (Windows)

Si deseas clonar este repositorio y probar los scripts de segmentación en tu máquina local, puedes configurar tu entorno siguiendo estos pasos:

1. **Clona este repositorio:**
   ```cmd
   git clone https://github.com/Shayko-stack/PYTHON_PROYECTS.git
   ```
2. **Navega al directorio del repositorio:**
   ```cmd
   cd PYTHON_PROYECTS
   ```
3. **Crea un entorno virtual:**
   ```cmd
   python -m venv env
   ```
4. **Activa el entorno virtual (Windows):**
   ```cmd
   .\env\Scripts\activate
   ```
5. **Instala las dependencias básicas necesarias:**
   *(Asegúrate de tener instaladas las librerías base de los ejercicios)*
   ```cmd
   pip install opencv-python numpy matplotlib
   ```
6. **Ejecuta el script deseado:**
   ```cmd
   python nombre_del_script.py
   ```
